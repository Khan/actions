A PR that moves between reviewer installs, or across a major release, now gets a fresh full review instead of reusing the other reviewer's history. Every install posts as the same bot account, so staging used to read another install's reviews, fingerprint, and threads as its own: anchoring a fast round on a fingerprint it never took, resolving threads it never opened, and dismissing a block it never raised. The version footer now carries an `install <workflow>` segment. Staging compares the newest bot review's install and major version with this run's, and a mismatch or an unreadable footer stages a first encounter (no prior reviews, no bot threads, no cache anchor, full depth, plan reason `foreign-history`). The other reviewer's open threads are left for a human. A minor or patch bump of the same install keeps its history. Because reviews posted before this release carry no `install` segment, each open PR gets one full review at its first push on this release.
